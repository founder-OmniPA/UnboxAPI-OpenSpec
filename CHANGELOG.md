# Changelog

All notable changes to the SemanticMap spec are recorded in this file. The
format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-05-23

### Added
- Initial public release of the SemanticMap schema (JSON Schema, draft 2020-12).
- Pizza reference example (`schema/examples/pizza.semanticmap.yaml`).
- README, SECURITY.md, CODEOWNERS, CI workflow, Apache-2.0 LICENSE, NOTICE.
- Sigstore-signed release tag and CycloneDX SBOM.

### Out of scope at v0.1.0
- No reference implementation, no LLM mapper, no safety-proxy runtime.
- No external contributions accepted at this tag.
